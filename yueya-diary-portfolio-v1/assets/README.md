# Product Screenshots

Place real screenshots from the WeChat Mini Program in this folder.

Suggested filenames:

- `01-home.png`
- `02-daily-checkin.png`
- `03-feeding-sleep.png`
- `04-history.png`
- `05-wechat-preview.png`

Before publishing screenshots, check for:

- WeChat IDs;
- phone numbers;
- real baby names;
- personal photos;
- QR codes;
- AppID / secret values;
- cloud environment credentials;
- private test-user information.

The product UI should remain in Chinese. Use English captions in the main README to explain what each screenshot shows.
