# 悦芽日记

悦芽日记是一款面向中国家庭的微信小程序，用于记录宝宝每日照护情况，帮助家长更清楚地了解宝宝在育儿嫂照护期间的状态，并形成持续、结构化的成长记录。

[English README](README.md)

## 项目起因

这个项目来自一个非常具体的家庭场景。

当父母白天需要工作时，宝宝通常由育儿嫂照护。家长很难实时知道宝宝今天喝了多少奶、睡了多久、吃了什么辅食、情绪怎么样，也不希望每天通过频繁询问的方式去“管理”育儿嫂。

真正的问题并不只是“缺少记录”。

更深层的问题是：

> “我不在宝宝身边，所以我不知道今天发生了什么。”

悦芽日记希望通过一个轻量、结构化的每日记录方式，降低这种不确定感。

## 解决的问题

传统的照护沟通往往依赖：

- 微信零散消息；
- 口头汇报；
- 手写记录；
- 照护者自己的记忆。

这会带来几个问题：

- 信息零散，不方便回看；
- 不同日期、不同育儿嫂的记录方式不一致；
- 很难比较宝宝的作息变化；
- 育儿嫂更换时缺乏历史参考；
- 家长上班期间容易因为不了解宝宝状态而焦虑。

## 产品定位

悦芽日记不是一个“监工工具”。

它更像是家庭和照护者之间的结构化沟通工具。

育儿嫂在一天中完成简单记录，家长下班后可以统一查看，而不是不断通过微信询问。

## 第一版功能

目前第一版包括：

- 日期自动记录；
- 单个 / 多个育儿嫂；
- 大运动记录；
- 喝奶时间和毫升数；
- 辅食类别；
- 过敏确认；
- 睡眠时间；
- 哄睡方式；
- 洗澡；
- 音乐 / 听一听；
- 阅读时间、书名、页数；
- 情绪；
- 体温；
- 便便颜色和形态；
- 散步；
- 备注；
- 历史回看；
- 数据导出。

## 产品思路

这个项目最核心的一点，是把“工具需求”和“情绪需求”放在一起考虑。

对很多重新回到工作的家长来说，焦虑并不是因为没有一张数据表，而是因为：

“我今天没有亲眼看到宝宝。”

所以产品的价值不只是“记录”，而是：

- 让照护过程更透明；
- 让家长减少反复询问；
- 让育儿嫂有明确记录方式；
- 让宝宝的照护历史可以持续积累。

## 为什么选择微信小程序

目标用户是中国家庭，所以微信小程序是最自然的载体。

原因包括：

- 不需要额外下载 App；
- 家长和育儿嫂都熟悉微信；
- 使用门槛低；
- 适合家庭内部传播；
- 方便通过体验成员进行早期内测。

## 为什么产品只有中文

这是一个明确面向中国家庭、依赖微信生态、围绕育儿嫂照护场景设计的产品。

因此，产品界面保持中文是有意的产品决策，而不是国际化尚未完成。

GitHub 默认 README 使用英文，是为了让海外招聘者和合作方也能够理解这个项目；中文版则用于完整保留真实产品语境。
